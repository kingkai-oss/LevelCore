# LevelCore Gaming Website

A static HTML/CSS/JavaScript website ready for GitHub Pages or Cloudflare Pages.

## Before publishing
1. Open `script.js`.
2. Replace `jamessalie712@gmail.com` with your real business email.
3. Edit prices, games and wording in `index.html`.
4. Replace the review placeholders only with genuine customer reviews.

## Publish
### GitHub Pages
Create a public repository, upload the three files, then enable Pages from the repository settings. GitHub Pages can publish static HTML/CSS/JavaScript files.

### Cloudflare Pages
Create a Pages project and use Direct Upload to upload the site files. The top-level `index.html` is the entry page.

## Important
Check each game's Terms of Service before offering account-sharing, boosting or leveling services. Do not collect customers' banking passwords, card details, 2FA recovery codes or other unnecessary sensitive information.
